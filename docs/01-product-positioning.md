# 01 — 产品定位

## 产品边界：做什么 vs 不做什么

### 我们做

| 方向 | 说明 |
|------|------|
| 非结构化→结构化 | 将 JD、简历等非结构化文档转化为结构化人才数据 |
| 辅助判断 | 为 HR 提供匹配分析、候选人画像，辅助决策 |
| 人才沉淀 | 将每次招聘的候选人信息沉淀为可复用的人才资产 |
| 效率工具 | 减少 HR 在信息整理、筛选、查找上的时间消耗 |

### 我们不做

| 方向 | 说明 |
|------|------|
| 自动投递/沟通 | 不是 Boss 直聘机器人，不自动触达候选人 |
| 替代 HR 决策 | AI 提供分析，HR 做决策 |
| 招聘渠道管理 | 不对接 Boss、猎聘、拉勾等渠道 |
| 薪酬/入职系统 | 不涉及 offer 审批、薪酬计算、入职流程 |

## 为什么不是"招聘机器人"？

市场上已有大量"AI 自动投递"、"AI 批量沟通"类工具。这类产品有两个核心问题：

1. **平台封禁风险**：Boss 直聘等平台对自动化行为打击严厉
2. **价值定位模糊**：把 HR 变成"AI 操作员"，本质是降级而非赋能

我们的定位是**智力增强（Intelligence Augmentation）**，不是**流程自动化（Process Automation）**。AI 的价值在于处理信息复杂度，不在于替代人的判断。

## 目标市场

### V1：个人作品 / 面试展示

- 不面向真实付费用户
- 面向 GitHub 访客和面试官
- 证明 AI + 招聘场景的产品设计能力

### 未来：中小企业（50-500 人）

- 无专职招聘系统（用 Excel 管理候选人）
- 年招聘量 20-200 人
- 对 AI 工具接受度高
- 无法承受大型 ATS（如 Greenhouse、Lever）的成本和复杂度

## 竞品差异化

| 维度 | 传统 ATS | AI 招聘机器人 | 我们 |
|------|---------|-------------|------|
| 核心价值 | 流程管理 | 批量触达 | 智能分析 |
| AI 角色 | 无/弱 | 自动化工具 | 分析助手 |
| 数据结构 | 表单字段 | 原始文本 | 结构化画像 |
| 人才沉淀 | 简历堆砌 | 无 | 可搜索人才库 |
| 使用门槛 | 高 | 中 | 低 |

## 产品原则

1. **AI 辅助，非 AI 替代** — 所有 AI 输出都可被 HR 修改和覆盖
2. **Schema First** — 所有 AI 输出都有明确的数据结构约束
3. **可解释** — AI 的分析结论必须附带原因，而非黑盒评分
4. **渐进式** — 从核心智能能力出发，逐步扩展为完整招聘系统
