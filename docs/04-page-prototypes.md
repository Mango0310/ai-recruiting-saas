```
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  ┌─ 匹配维度明细 ──────────────────────────────────────┐   │
│  │                                                     │   │
│  │  AI理解(40%)    ████████░░  高                       │   │
│  │  产品能力(30%)  ███████░░░  中高                      │   │
│  │  项目经验(20%)  ████████░░  高                        │   │
│  │  学历(10%)      ██████████  匹配                      │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  [打印报告]  [分享给Hiring Manager]  [导出PDF]               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**设计原则：**

1. **不以分数为核心**：不显示"匹配度 86%"，而是用星级和结论文字概述
2. **优势/不足并列**：让 HR 一眼看到正反两面
3. **可操作的建议**：面试建议直接可用，而非泛泛的"建议面试"
4. **维度明细可折叠**：想看细节的人展开，不想看的人看结论即可
5. **保留人工判断空间**：结论是"推荐"而非"必须"

## 页面层级关系

```
Dashboard
  │
  ├── Job Detail
  │     ├── [岗位画像 tab]
  │     ├── [候选人列表 tab]
  │     │     └── Resume Upload (可从列表页进入)
  │     └── [匹配分析 tab]
  │
  ├── Candidate Profile
  │     └── AI Match Report
  │
  └── Talent Pool (人才库搜索)
        └── Candidate Profile (只读)
```
