## 岗位创建流程（详细）

```
HR 进入系统
    │
    ├── 输入岗位名称："AI产品经理"
    ├── 粘贴 JD 文本（或上传 JD 文件）
    ├── 点击"AI 分析"
    │
    ▼
AI JD Analyzer
    │
    ├── 解析 JD 文本
    ├── 提取：岗位职责、必备能力、技能标签、经验要求
    ├── 生成 Job Profile JSON
    │
    ▼
HR 确认页面
    │
    ├── 查看 AI 生成的岗位画像
    ├── 修改/补充信息
    ├── 确认保存
    │
    ▼
岗位创建完成 → 进入候选人筛选阶段
```

## 简历处理流程（详细）

```
HR 上传简历（单个/批量）
    │
    ├── 拖拽 PDF 文件到上传区域
    ├── 显示上传进度
    │
    ▼
Resume Parser
    │
    ├── Step 1: PDF 文本提取（PyMuPDF）
    ├── Step 2: 文本清洗（去噪、分段）
    ├── Step 3: LLM 结构化抽取
    │       ├── 基本信息（姓名、年限、学历）
    │       ├── 技能标签
    │       ├── 工作经历（公司、职位、时间段、项目）
    │       ├── 教育背景
    │       └── 其他（证书、语言）
    ├── Step 4: Schema 校验
    │       ├── 必填字段检查
    │       └── 格式标准化
    ├── Step 5: 保存 Candidate Profile
    │
    ▼
候选人列表更新
    │
    ├── 新候选人出现在列表中
    ├── 状态：待分析匹配
    │
    ▼
触发 Match Analysis
    │
    ├── 获取 Job Profile
    ├── 获取 Candidate Profile
    ├── LLM 匹配分析
    └── 生成 Match Report
```

## 人才库搜索流程

```
HR 输入搜索条件
    │
    ├── 关键词："AI Agent"
    ├── 技能标签："Python"
    ├── 行业："企业服务"
    │
    ▼
搜索候选人才库
    │
    ├── 匹配技能标签
    ├── 匹配项目关键词
    ├── 匹配行业经验
    │
    ▼
搜索结果列表
    │
    └── 查看历史候选人画像 + 之前的匹配记录
```
